# Opportunity Radar (starter app)

A tiny static web page listing opportunities for TAISP scholars.

- `index.html`: page structure
- `app.js`: loads `opportunities.json` and renders cards
- `style.css`: styling
- `opportunities.json`: the data (title, type, tags, deadline, link)

## Conventions
- Plain HTML, CSS and JavaScript. No frameworks or build step.
- Run locally with `python3 -m http.server` in this folder (fetch needs a server).
- Keep changes small and explain them simply; the user is a beginner.
- Do not present sample data as real opportunities.
