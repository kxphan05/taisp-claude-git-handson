# TAISP Hands-on: Git + Claude Code

A self-paced workshop for TAISP scholars with little or no hackathon experience. In about 90 minutes you will learn the two skills you need most for the **TAISP Beginner Mini Hack** (theme: *Build for TAISP*):

1. **Git and GitHub**: save your work, work in branches, open pull requests, resolve conflicts.
2. **Claude Code**: an AI coding assistant in your terminal. Learn to prompt it, review its output, and stay in control.

No prior experience needed. Seniors are welcome to mentor.

## Labs

| # | Lab | Time | You will learn |
|---|-----|------|----------------|
| 0 | [Setup](labs/00-setup.md) | 15 min | Install Git, GitHub CLI, Claude Code; fork and clone this repo |
| 1 | [Git basics](labs/01-git-basics.md) | 20 min | `status`, `add`, `commit`, `log`, `diff` |
| 2 | [Branches and pull requests](labs/02-branches-and-prs.md) | 20 min | Branching, pushing, opening your first PR |
| 3 | [Merge conflicts](labs/03-merge-conflicts.md) | 15 min | Why they happen and how to fix them calmly |
| 4 | [Claude Code basics](labs/04-claude-code-basics.md) | 20 min | Prompting, reviewing diffs, permissions, `CLAUDE.md` |
| 5 | [Build a feature with Claude Code](labs/05-build-with-claude-code.md) | 30 min | Use Claude Code and Git together on the starter app |
| 6 | [Scope your MVP](labs/06-scope-your-mvp.md) | 15 min | Turn an idea into something shippable in 24 hours |

Do them in order. Each lab has a **Checkpoint**; if you can tick it, move on.

## Ground rules for using AI

- AI coding assistants are allowed in the hackathon, but **every team member must be able to explain the core parts of the project**.
- Always read the diff before you accept a change. Claude is a fast junior teammate, not an oracle.
- Never paste secrets (API keys, passwords) or real scholar data into prompts or commits.
